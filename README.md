# nosaverguenzan.org

Web de la enmienda a la totalidad «Ustedes NOS AVERGÜENZAN».

- Sitio estático con Jekyll, publicado en GitHub Pages por el flujo `.github/workflows/publicar.yml`.
- Las noticias están en `_posts/` y se editan con Pages CMS (configuración en `.pages.yml`).
- El estado del procedimiento (registro, expediente) está en `_data/estado.yml`.
- Los PDF de `descargas/` no deben modificarse: su huella SHA-256 está publicada en `/verificacion/`.
- Licencia: todo el contenido se dedica al dominio público con CC0 1.0 Universal (ver `LICENSE`).
